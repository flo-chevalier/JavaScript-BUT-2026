# Exercices bonus

## Ajouter un élément au DOM

### Étape 1
On va présenter quelques personnes (prénom, nom) dans une liste.
On utilisera une balise `<ul>` et des balises `<li>`.

```html
<ul>
  <li>John Doe</li>
  <li>Jane Doe</li>
</ul>
```

### Étape 2
On ajoute une balise `input` et un bouton `Valider` pour ajouter une nouvelle personne.

```
<input type="texte"></input>
<button>Valider</button>
```

### Étape 3
Quand on clique sur le bouton, on ajoute la personne dans la liste.
